# Graham & Harper Family Tree — handoff

Live site: https://artificialfear.github.io/family-tree/
A Thanksgiving 2026 gift for Mat's mom, Renee. Interactive illustrated family tree with story mode, map, timeline, sources, music, and shared family memories.

## How it's built
- `src/` is the source. **Edit these, never index.html.**
  - `src/index.html` — page shell with `<!--CSS-->` and `<!--JS-->` slots.
  - `src/css/*.css` — joined in name order (`main.css`, `tree-art.css`).
  - `src/js/*.js` — joined in name order inside one `{ … }` block: `00-family-data` (people, photos, events, story text), `01-core` (helpers, state), `02-chart`, `03-tree` (illustrated tree, sky, gestures, memory stars), `04-panel` (person panel, forms, help, poster), `05-music`, `06-story`, `07-cover`, `08-map-timeline`, `09-memories` (backend, passcode, voice recording/playback).
  - `src/mapdata.json` — map shapes (fills `__MAP__`). `src/api.txt` — Apps Script `/exec` URL (fills `__API__`; empty = memories off).
- `python3 build.py` rebuilds `index.html`. Run it after every change and commit the result. `--api URL --out FILE` builds a variant (tests use this).
- `photos/` — portraits (`p-<id>.jpg`), gallery photos, `drift/` cover photos, `qr.png` (points at the live site).
- `music.mp3` — background music (new track 2026-11-21, leading silence trimmed, fade-out ending removed). Plays an 18.2 s intro once, then loops samples 803,636–4,914,827 (93.2 s) counted from the first sound; `LOOP_START`/`LOOP_END` in `src/js/05-music.js`. The song has no exact repeat, so the loop point was chosen where harmony and texture match (≈18.6 s ↔ 111.8 s in the original) and a 2 s equal-power crossfade is baked into the file before the loop end, plus 2 s of post-loop audio as a safety tail.
- The old claude.ai artifact copy is retired; GitHub is the only source.

## Shared memories backend
- `backend/Code.gs` — Apps Script bound to a Google Sheet in Mat's **personal** Google account (mathew.t.graham@gmail.com).
  - Sheet tab `Memories`: one row per memory/photo/answer/correction/added relative/voice memory. Typing anything in `hidden` removes a row from the site. Missing header columns (e.g. `audio`) are appended automatically.
  - Drive folder `Family Tree Uploads`: photos are shared "anyone with link, view" (shown via drive.google.com/thumbnail). Voice recordings are **not** shared; the page fetches them through the script (`GET ?audio=<fileId>` → `{ok,mime,b64}`), which only serves files inside that folder. Max 6 MB per recording; the page caps recordings at 2 minutes.
  - Family passcode in Script Properties (`FAMILY_CODE`), set from the sheet menu Family Tree > Set family passcode. Not case-sensitive. `change-me` is never accepted.
- Reads (GET) are open; writes (POST, text/plain JSON, actions `check`/`add`/`del`) need the passcode. The page asks once per device and remembers it.
- Lockout: 5 wrong passcodes from one device, or 25 from everyone combined, locks writes for 15 minutes (CacheService). The page shows a "wait 15 minutes" message.
- Each device has a random id kept in its browser; the Sheet's `by` column stores only its SHA-256 hash, so the public hash can't be used to delete posts. Only the device holding the original id can remove its own posts. Mat moderates by editing the Sheet.
- The page re-checks for new memories every 90 s and when the tab regains focus.

## Tree art
- Default look (2026-11-21): the **painted tree** on the original sky and planet — dense hand-painted leaf canopy (baked into the background picture), a broad shaded trunk that meets the planet, and names on small paper scroll banners. `painted()` in `03-tree.js` builds it; `?tree=classic` brings back the older ink-line tree; `?style=parch` is a parchment-paper variant Mat tried (not used).
- Leaves grow on twigs (2026-11-22, Mat: no free-floating leaves, but don't look thinned out): `painted()` sprouts twigs from every canopy branch (every 36–58 units, alternating sides, one level of sub-twigs) and 4+r/16 twigs from behind each photo, all kept inside the canopy outline; leaves sit in alternating pairs every 12–19 units along each twig plus one at the tip, and along thin branches. `?leaves=scatter` shows the older random scatter (which skipped 50% of spots).
- Name scrolls and the sky banner use `wornScroll()` (rough edge points seeded by the name's hash so each scroll's edge is fixed, gradients `#scrollG`/`#scrollBurn`/`#scrollT` in `SCROLLDEFS`, offset shadow path, faint stains, folded tails). No SVG filters, so it's cheap on phones. A cover-page rule `.leaf path{stroke-dasharray:1}` was leaking onto the scrolls and drew dotted edges; `.scroll path` now resets it.
- Scroll labels that would overlap are nudged sideways (`LDX` in `drawLeafTree`).
- Grow animation: during the grow the baked canopy picture is copied once into a canvas (`#tgrowcv`, ≤1400 px wide on phones) and revealed by painting a growing circle there each frame; the real `#tbackimg` is hidden until the grow ends. (A per-frame CSS `clip-path` on the big image made Android re-paint it and flash.) Growth waits for the bake and canvas prep (max 2.2 s); `#tworld.pre` stays on until growth actually starts so faces don't show early.
- `bakeArt` skips re-baking when the same canopy picture is already showing, and shares an in-flight bake (`bakePend`); the canopy SVG takes over a second to rasterize, so re-draws after memories load used to hide and re-show it (and restart the sway). Sway keyframes start and end at rest.
- Sky pieces (`skyMarkup()`, `renderNewest()`, `openConst()` in `03-tree.js`): title banner centered over the trunk just above the canopy (`SKYG.by` = canopy top − 135, raised at Mat's request; `TB.y0` is extended so Fit includes it), newest-memory pill under it (5 newest story/photo/answer posts, rotates every 9 s, pauses while dragging; tap opens the memory), G and H star constellations either side of the banner (`#tconstG`, `#tconstH`; tap shows the 'Ed and Renee' story chapter + 'Read the whole story'; Mat chose letters over a heart; **switched off 2026-11-22** via `SHOWCONST=false`). Live tree only (not poster/print).
- Toy-theater stage theme (2026-11-22, inspired by Pizza Moon photos Mat sent) is now the DEFAULT; `?theme=classic` shows the previous look. `stageFrame()` draws a proscenium overlay (`#proscen`: valance with red/green swags, gold fringe and crescents, tied-back side curtains, apron with footlights) and `stageBackdrop()` draws cut-out cloud rows and gold stars on strings into the sky; both redraw only on resize. Paper grain + vignette on the sky only. Gold-rimmed sun/moon (moon has a crescent behind). Engraved crosshatch on the trunk (`#hatchA/B`, masked to the edges) and planet rim (`#phatch`), ink outlines on leaves and branches. `stageDims()` tells `tFrame` how much the frame covers so Fit keeps everyone inside it. Original art only — nothing copied from the restaurant. Round 2: star strings run up behind the valance; sun/moon faces were tried (`faceSVG`, still in code) but Mat reverted to the gold-rimmed sun disc and moon with crescent; the family title is a lit marquee sign (`marqueeSVG`, `#marquee`) fixed at the top under the toolbar, with the newest-memory line under it (the in-tree banner is skipped in this theme). Fit keeps the family below the sign; on phones the tree is top-aligned under the sign.
- Toolbar (Mat, 2026-11-22): search box `#q`, zoom `#tzin/#tzout` and larger-text `#tBig` are `hidden` in the HTML (kept so their JS still binds). The sky always opens at night (`SKYPREF=SKYQ||'night'`, stored preference ignored on load).
- Opening curtain (stage theme, 2026-11-22): `07-cover.js` adds `.cover.curtain` with two velvet panels (`.cpanel`) and the stage frame (`.cframe`, same `stageFrame()` art; CSS selectors shared with `#proscen`). The tree is drawn full-screen behind it on load; `openCurtain()` requests browser full screen, waits for `lastBake`, then waits until the window size has been still for 320 ms (max 1.6 s; the full-screen switch resizes it on phones), refits the tree, and only then scales the panels away (1.8 s). Valance and apron heights depend on width only, so the frame doesn't reshape when the height changes and hides the cover, starting the story if chosen. The grow animation and gold-sketch morph are skipped in this theme (still used by `?theme=classic`).
- Stage navigation (2026-11-22): in the stage theme `body.tfull` is permanent (`setFull(false)` is a no-op), the page header/tabs are hidden (`body.stagemode`), `#tFull` is hidden, and the toolbar has `#tHelp` ('Can you help?') and `#tProg` ('Program ▾' → Chart, Map, Timeline, Sources). `route()` keeps `#v-tree` on and shows the chosen section as `.view.sheet` (fixed page over the stage, z 29, with a '✕ Back to the tree' `.shclose`); Escape closes the sheet. The opening curtain's frame gradients are renamed (`cprg` etc.) so they don't hijack the stage's ids.
- Layout (2026-11-22): `#marquee` sits at the top (6 px; 4 px on phones); the stage toolbar is at the bottom above the apron (`--apron`, `--tbh` set in the stage `draw()`), the Program menu opens upward, and the story card and hint sit above the toolbar. `tFrame` reserves the toolbar height; `tClamp`'s minimum zoom is now 50% of fit-to-screen (was 75%, which stopped Fit from shrinking the tree enough). Phones: moon/sun sit under the memory line on the right (`--mqb`) and the tree starts below them.
- Opening card photos: in curtain mode `#drift` is moved inside `.coverIn` (clipped, masked darker in the middle, images at 22% opacity) instead of spanning the screen.
- Animated view changes (`tApply(true)`: story steps, Fit, focus) glide on the compositor: the tree SVG is drawn at one end of the move and `#tsvg` (class `tglide`) slides between the views with the same .9 s easing as the canopy layers; falls back to the old per-frame `#tworld` transition only when the pre-drawn 180% area can't cover the screen (`glideOK`). Gestures call `endGlide()` first. In the story, dimming/select/spotlights wait 960 ms until the move ends (`stepT`).
- Phones (<700 px stage): animated view changes don't slide at all — `tApply` adds `#tstage.tswap` (fades `#tsvg/#tback/#tfront` out in .18 s), jumps while hidden, and fades back in (.28 s) after two frames. Sliding a 180% layer made Android show stale tiles ('duplicated screen swiping'). Sign is 64% wide on phones.
- Phone calm-down (Mat still saw story glitches + sign flicker): under 700 px, leaf/branch opacity transitions, spotlight pulses and in-tree memory-star twinkles are off; story highlighting is applied 120 ms into the fade-out; fade-in waits 2 frames + 140 ms. `#marquee .mqsign/.mqnew` get their own compositor layers. Root cause (found from Mat's screen recording): `aside.panel.fresh` runs a slide-in keyframe animation whose transform overrode the closed drawer's translateX(105%), so the hidden panel flashed across the screen on every `select()`. Fixed with `body.tfull:not(.pdrawer) aside.panel.fresh{animation:none}`.
- Curtains are purple/celestial by default (`PURP`; `?curtain=red` brings back red): purple `#prg`, midnight-blue `#pgg`, gold star/crescent pattern `#pstp` over the side curtains and front swags; the opening curtain's frame renames its ids (`cprg`, `cpstp`…) so the stage doesn't reference the hidden cover's defs.
- Stage moon (2026-11-22, Mat picked design #2 of six mockups): `paperMoonSVG()` replaces the phase moon inside `#moonBtn` in the stage theme — gold paper-cut crescent (circle minus offset circle masks), cut-paper shadow, string running up behind the valance.
- Sunset sun x follows the trunk (`--sunx`, set by `sunToTrunk()` on first framing and Fit; panning leaves it put; glides .9 s on Fit).
- Crowding: right after `tLayout()`, `drawLeafTree` treats each person as a photo box plus a scroll box and pushes overlapping people apart sideways (photo and scroll move together, so names stay centered); branch ends touching a moved photo follow it. Bottom row spacing: son→wife 190, wife→next son 215, grandchildren 112 apart.
- Memory stars sit inside the tree beside the person each memory is about (`#tmstars`, placed around the photo avoiding faces and labels), and grow when zoomed out (`--msk`) so they stay visible. If no free spot exists, the star falls back to the sky.
